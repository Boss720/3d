      How GPU + CPU works

      GPU estimates neural depth while CPU work decodes, refines and renders video frames. The stages can overlap. Video encoding tries NVIDIA NVENC after a local check; StereoLab falls back to CPU encoding if needed. Some model operations may run on CPU through ONNX Runtime.

      Capability status reports the input caps and how unknown adapter memory is treated. Large uses the limited-memory cap when memory is known to be at or below the reported threshold, or when the runtime conservatively treats unknown memory as limited. Auto/Hybrid can fall back to CPU after GPU inference failures; explicit GPU mode reports them.

      ABOUT STEREOLAB

      A different dimension.
      On your own device.

      StereoLab is an independent stereo conversion studio. Neural depth models run locally through ONNX Runtime. The visual approximation uses image cues and is not AI depth.

      Model installation requires internet access. Media processing stays on this local server. Large models and video conversion can take time on CPU.
