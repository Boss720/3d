Checking local GPU support…

High speed impact for neural models. Video encoding also uses NVENC when your FFmpeg passes its hardware check.

How GPU + CPU works

GPU + CPU and NVIDIA GPU modes require the NVIDIA DirectML adapter for neural depth. Hybrid mode uses CPU to decode, refine and render video frames while NVIDIA handles depth; these stages can overlap. Video encoding tries NVIDIA NVENC after a local check; StereoLab falls back to CPU encoding if needed. Some model operations may run on CPU through ONNX Runtime.

Capability status reports the input caps and how unknown adapter memory is treated. Large uses the limited-memory cap when memory is known to be at or below the reported threshold, or when the runtime conservatively treats unknown memory as limited. Auto can fall back to CPU after GPU inference failures; GPU + CPU and NVIDIA GPU modes report them.

Optional input detail measurement

Measures depth-input inference on a separate proxy capture of one frame at 256, 384, and 518 px, regardless of the preview detail selector. This is not a full-source calibration and does not compare exports, encoders, or quality. One inference already in progress cannot be interrupted, so the run may exceed its time budget.

      StereoLab is an independent stereo conversion studio. Neural depth models run locally through ONNX Runtime. The visual approximation uses image cues and is not AI depth.

      Model installation requires internet access. Media processing stays on this local server. Large models and video conversion can take time on CPU.
