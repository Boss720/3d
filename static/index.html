How GPU + CPU works

GPU estimates neural depth while CPU work decodes, refines, renders and encodes video frames. Video stages can overlap. Some model operations may run on CPU through ONNX Runtime. Performance depends on the model and hardware.

For a GTX 1650 Ti with 4 GB VRAM, start with Small. Large uses CPU in Auto or hybrid mode.

ABOUT STEREOLAB

A different dimension.
On your own device.

StereoLab is an independent stereo conversion studio. Neural depth models run locally through ONNX Runtime. The visual approximation uses image cues and is not AI depth.

Model installation requires internet access. Media processing stays on this local server. Large models and video conversion can take time on CPU.
