# StereoLab QoL batch - 20 October 2026

Implemented the first bounded slices from the additional roadmap recommendations.

- Queue pause/resume takes effect between jobs, including new admissions and preview clips. The active job finishes; shutdown wakes the paused worker. Pause resets on a new server launch. Canceling pending work while paused completes cancellation and cleanup immediately without consuming another queue task.
- Windows output folder/reveal actions accept managed paths and known completed job IDs. Save copy accepts an existing writable folder, reserves a unique destination exclusively, preserves the managed original, rejects temporary/model destinations, and removes its own partial failed copy where possible.
- Storage inventory reports managed uploads, preview segments, outputs and models. Explicit selected-file cleanup is restricted to inactive temporary files; models/outputs are read-only in this panel. Active sources, staged uploads and active proxy work are protected again at deletion. Failed per-job cleanup can be retried. Inventory scans run outside global queue/job locks.
- A canceled/failed streamed upload always unregisters staged ownership, including when a Windows file lock prevents cleanup. Its retained file is then available as an inactive cleanup candidate.
- Each video job owns reusable stereo rendering scratch buffers. XREAL packing fills one combined canvas. Output arrays remain independent across frames, and state is bounded to the current source shape.

Direct per-job conversion destinations are deliberately still a separate roadmap slice: durable history currently records managed output basenames. Save copy offers destination selection while preserving that existing lookup contract and consumes additional disk space. Source retention, projects, video-depth caching, active-video pause, model/output deletion controls and interrupted-video recovery remain planned.
